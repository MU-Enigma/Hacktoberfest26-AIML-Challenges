# Level 3: Build It

Pick **one** option and work in your own folder inside it. Full task description is in the [main README](../README.md#level-3-build-it-standalone).

| Option | Folder | What you build |
|--------|--------|----------------|
| A | [`A_ngram/`](A_ngram/) | An n-gram text generator (command line tool) |
| B | [`B_tokenizer/`](B_tokenizer/) | A byte-pair-encoding (BPE) tokenizer |

## For both options

- Work in `Level_3/<option folder>/<your-github-username>/`
- Include **your own tests** and say how to run them
- Add a `README.md` in your folder with how to run your code and one example run
- Put a **design decision** in your PR description: one real decision you made, the alternative you rejected, and why
- We also run our own checks against the spec when reviewing, so follow the interface, file names and rules exactly
- One open Level 3 PR at a time. A second option is a bonus and is reviewed last.

You may use AI tools, but disclose which parts they influenced and be able to explain every line.
