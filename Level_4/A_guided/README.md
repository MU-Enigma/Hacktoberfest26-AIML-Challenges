# Level 4, Option A: Guided

The project is **[`lunch-lab/`](lunch-lab/)**, a small NumPy-only ML pipeline that we broke on purpose. Each broken or missing piece is an issue in this repo tagged `level4-guided`.

1. Read [`lunch-lab/README.md`](lunch-lab/README.md) and get the tests running.
2. Open the Issues tab, filter by `level4-guided`, and pick one (labels: `easy`, `medium`, `hard`).
3. Fix it on a branch and open a PR. Only change the files the issue needs. Add a test that fails without your fix and passes with it.
4. Fill in the PR template, including which AI tools you used. You must be able to explain every line.

There is no log file for this option. Your merged PR is the record.
