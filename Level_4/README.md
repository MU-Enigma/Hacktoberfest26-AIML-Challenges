# Level 4: Real Open Source

Option A happens inside this repo. Option B happens in **other repositories**, and this folder only holds a small log file for it.

| Option | Folder | What it is |
|--------|--------|------------|
| A | [`A_guided/`](A_guided/) | Fix a known bug or rebuild a missing piece in `lunch-lab`, a small project we broke on purpose. The work happens in this repo. |
| B | [`B_real/`](B_real/) | Contribute to a real open-source AI/ML project online. The maintainers are strangers and the outcome is not in our hands. |

Pick **one** option. The full description, the list of projects and the "how to pick an issue" guide are in the [main README](../README.md#level-4-real-open-source).

## Logging

- **Option A:** no log file. Open your PR here, and it is the record.
- **Option B:** open your PR in the project's own repo, then open a small PR **here** adding `Level_4/B_real/<your-github-username>.md`, using the template in that folder's README.
